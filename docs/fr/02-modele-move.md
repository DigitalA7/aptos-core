# 2. Modèle Move et modules

Aptos met Move au centre de la création d’applications. Les modules décrivent des ressources et des fonctions dont la composition permet de gérer des actifs avec des règles explicites.

Une DApp doit distinguer ses modules, les ressources persistantes et les transactions qui les modifient. Cette organisation rend les invariants métier visibles dans le code, mais impose de comprendre les types, capacités et permissions propres à Move.
