# 4. SDK et intégration applicative

Le dépôt contient un dossier sdk ainsi que des interfaces API et des outils d’écosystème. Une DApp s’appuie sur ces surfaces pour construire des transactions, interroger l’état et suivre les réponses du réseau.

L’intégration doit conserver la séparation entre clés de signature, paramètres réseau et logique d’interface. Les guides officiels et tutoriels liés depuis le README complètent la lecture du dépôt pour les choix de production.
