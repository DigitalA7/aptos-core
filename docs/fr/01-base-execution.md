# 1. Aptos comme base d’exécution

Aptos est une blockchain de couche 1 conçue pour les applications Web3. Le dépôt aptos-core rassemble le nœud, le runtime Move, le réseau, le consensus, le stockage et les SDK nécessaires à l’écosystème.

Pour une DApp, ce dépôt sert surtout à comprendre la frontière entre application Move, nœud et outils clients. Le code source est plus large qu’une DApp isolée : le parcours sélectionne les composants utiles à l’intégration.
