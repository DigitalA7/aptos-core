# 5. Sécurité et périmètre

Aptos Core est un socle complet : les enjeux couvrent Move, le consensus, le stockage, le réseau, la synchronisation et les interfaces client. Une DApp ne doit pas supposer que le SDK remplace la validation de ses permissions, montants ou états.

Le README référence une licence source spécifique au projet Aptos. Il faut donc vérifier les conditions exactes avant redistribution commerciale.

Cette série est documentaire : aucune installation, compilation, exécution ou déploiement n’a été réalisé. Pour une validation active, consulter les tests et guides du dépôt sans considérer qu’ils ont été exécutés ici.
